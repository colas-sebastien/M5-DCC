# M5-DCC
Make your M5Atom or M5Stack control your model railways via DCC protocol.

## Introduction
The goal of this project is to port the [D17 project](https://github.com/ullysse/d17) on M5Stack devices.

The project contains a web server with web resources (html,css,js). To have an easy way to manipulate files, all the files will be store on an SDCard that's why the project currently supports:
- [M5 Atom + TF card reader](https://shop.m5stack.com/products/atom-tf-card-kit)

In the future it is planed to also support all M5Stack devices with integrated SD Card reader like:
- [M5Stack Core](https://shop.m5stack.com/collections/controllers/CORE)
